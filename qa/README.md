# QA snapshots

This directory contains retained result snapshots from the tested private development build.

- `synthetic-results.json` records the deterministic/statistical suite result.
- `multiplayer-final-results.json` records the final eight-player multiplayer scenario result.

The private development workspace contains the Luau QA harnesses used to produce these results, including synthetic probability checks, multiplayer/concurrency scenarios and a long-running endurance pass.

These JSON files are evidence for that specific build. They should not be treated as a permanent guarantee for later revisions.
